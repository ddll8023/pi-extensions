# supervisor

Pi 任务级旁路监督扩展。使用独立上下文、无工具的模型请求，对照用户需求、项目规则、近期方案和确认记录，提示任务偏离、范围扩张、重复失败、无依据结论与授权依据不明的问题。

默认关闭。它只提供建议，不阻断主任务、不产生操作授权、不修改权限模式、不回滚，也不强制主 Agent 续跑。

## 使用

扩展加载后可使用以下命令：

```text
/supervisor on
/supervisor off
/supervisor status
```

- `/supervisor on`：在任务空闲且旧审查已退出时，确认额外模型消耗后开启。
- `/supervisor off`：关闭监督并请求取消进行中的审查，清除监督状态栏与 widget 提醒；已产生的消耗不能撤回。
- `/supervisor status`：显示固定模型、当前输入与分支的调用次数、提供方报告的用量、等待时间和最近状态，不发起模型请求。
- `/supervisor`：等同于 `/supervisor status`。

开启需要可交互的 UI、已配置认证的物理主模型，不使用 `pi-virtual` 虚拟模型。确认框会说明发送材料、额外消耗、等待时间及隐私风险。

本目录通过 package 的 `pi.extensions` 通配符 `./*/index.ts` 加载；添加本地源码不会自动更新通过 GitHub 安装的 package 缓存副本。

## 模型与审查材料

审查模型固定为开启时的主模型。切换主模型不会自动更换审查模型；需要更换时，先执行 `/supervisor off`，再执行 `/supervisor on` 并重新确认。固定模型不可用时不切换到其他模型或供应商。

审查只使用 Pi 当前有效会话投影和已加载的项目规则，不另行读取仓库文件，不发送完整系统提示。材料包含有界的用户需求、前置方案、确认记录、工具调用参数、工具结果与结论片段；不会提取思考块、图片数据或提供方签名。

长会话优先保留近期真实用户需求及其前置方案，其余历史按限额选取并标记截断。缺少某段记录不能据此断言该操作没有授权。

## 触发与限额

仅在已完成的 assistant 回合边界考虑审查，满足以下任一条件时触发：

- 自上次审查起累积 8 次工具结果；
- 连续 2 个有工具结果的回合包含失败；
- assistant 回合不再请求工具，即任务收尾。

有新输入排队、审查正在进行、本轮已失败或调用上限已达到时，不发起新的审查。回合边界会等待审查结果，不是完全并行的后台监督。

| 项目 | 限额 |
|---|---:|
| 每条真实用户输入的审查请求 | 最多 6 次 |
| 单次审查系统提示与材料合计 | 最多 16,000 字符，不是 token |
| 单次输出请求上限 | 1,400 token，同时受模型输出上限约束 |
| 单次超时 | 20 秒 |
| 单次问题数量 | 最多 3 条 |

审查失败后本轮不自动重试。关闭再开启不会重置本轮预算或失败状态；新的真实用户输入才会重置。存在尚未结束的提供方请求时，后续请求不会与它叠加。

## 提醒与权限边界

每条问题必须引用所给材料中的证据 ID 与原文。响应结构或引文不符合约定时，该次审查记为不可用，不伪装成“无问题”。引文核对仅证明原文存在，不保证模型判断正确。

- 状态栏显示审查状态、独立调用次数与已报告 token；有提醒时使用字符串 widget 展示。
- 工具回合自然继续时，仅把未重复的建议追加给主 Agent；同一条用户输入内按问题类别与引用原文去重。
- 任务收尾只展示提醒，不要求主 Agent 自动重做或续跑。
- “未发现有据问题”仅描述本次有界材料中的判断，不代表代码正确，也不产生任何授权。

监督者没有工具，不替用户确认操作，不建议越过项目约束的运行操作。主 Agent 仍需遵循真实用户要求与原有授权边界。

## 取消与分支状态

关闭监督、切换会话或分支、开始新的 Agent 运行及会话退出时，会请求取消旧审查并使旧上下文失效；旧结果不能覆盖新的任务或分支。

状态通过会话中的自定义 entry 保存，不把消耗统计加入主模型上下文。恢复同一会话或切换分支时，读取该分支的状态；fork 到新会话不能继承原会话的消费授权，需要重新开启确认。无 UI 时不自动恢复开启状态。

恢复状态若显示此前审查被中断，会标记为不可用，本轮不自动重试。分支累计消耗不会因关闭监督而清零。

## 消耗与隐私

开启后会向固定模型提供方额外发送审查材料，消耗 API 费用或订阅额度，并增加回合等待时间。

消耗统计独立于主 Agent，分别累计调用次数、输入、输出、缓存读写 token、请求字符数与等待时间。提供方未报告有效用量时标记为未知，不按零消耗处理；字符数不是 token，实际费用以提供方账单或额度记录为准。

材料会过滤常见凭据格式与敏感字段。对通过 `path` 参数直接指向常见凭据文件的调用，会省略参数和结果内容；这不覆盖所有工具参数形式，也不是完整脱敏或数据防泄漏保证。不要在包含机密的会话中开启。
