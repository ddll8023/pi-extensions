# token-rate

在模型生成期间，在 Pi 底部状态栏显示当前 AI 回复的实时速率和当前对话平均速率。

## 显示

```text
速率 实≈12.3/s 均≈10.8/s
```

- **实时速率**：最近 2 秒内的滑动速率，流式生成过程中持续更新；
- **平均速率**：当前 Pi 会话中所有 AI 回复累计计算，包含正在生成的回复；
- 回复完成后底部状态会自动清除，避免长期占用状态栏；
- 平均速率使用累计输出 Token 数除以累计生成时间，不包含用户等待、工具执行和空闲时间；
- 服务商提供流式用量时使用实际 Token 数，否则使用 Pi 的 `chars/4` 规则估算，并以 `≈` 标记；
- 当前会话结束后速率数据会重置。

速率统计包含文本、思考内容和工具调用输出。不同服务商的 Token 统计方式可能不同，估算值仅供参考。

安装整个扩展包后执行：

```text
/reload
```
